# Employee Attrition and Performance Analysis

TCS iON Industry Project (IP 45) built in Power BI.

## Overview
Interactive 3-page dashboard on HR data (1,470 employees) showing attrition by department, age group, gender and marital status, and the relation between salary and manager rating.

## Dashboard Pages
1. Overview: headcount, attrition rate, average salary
2. Demographics: attrition by gender, age group, marital status
3. Performance: salary vs manager rating, coloured by attrition

## Key Findings
- Overall attrition: 16.1%
- Highest in ages 26-35 (19.5%) and 18-25 (18.0%)
- Sales (~21%) and HR (~19%) higher than Technology (~14%)

## Dataset
The dataset is an HR employee dataset (1,470 employees) provided as 5 CSV files: Employee, PerformanceRating, EducationLevel, RatingLevel and SatisfiedLevel. The tables are linked in Power BI using relationships (see the Design Document). It is a publicly available sample dataset used for learning and is not real company data.
